# AGENTS.md

An offline WordNet dictionary, one headword per page. Read `../AGENTS.md`
first, and `README.md` for the keys and the data.

- `app/src/main/java/com/dictionary/xp3/`: `MainActivity` (the page, search
  box and keys) and `Dictionary` (reads the asset format).
- `app/src/main/assets/`: `words.dat` and `synsets.dat`, generated by
  `tools/build_dict.py`, whose docstring documents the format. They are
  stored uncompressed in the APK (`noCompress "dat"`) so the app can seek
  straight to a block; change the format in the script and `Dictionary`
  together, then rebuild the assets as `README.md` describes.
- Unlike the other apps, Dictionary has no `android/` level, no `:core` and
  no dependencies at all, not even `common/`.

```bash
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ./gradlew :dictionary:app:assembleRelease
```
