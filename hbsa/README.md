# HBSA, for the Sonim XP3

The posts of the club's Instagram, @hbsaasu, for someone without Instagram:
each post's picture and caption, newest first, and nothing else (no likes,
no comments). Above the list, a gold card shows the club's next event: the
soonest date that hasn't passed yet among those the captions mention. In a
post, the dates and times in the caption are marked in gold.

The posts are read the way `instagram_scraper.py` reads them: the public
profile page, fetched from the phone as a desktop browser would ask for it,
with the 12 latest posts in its embedded JSON. Nothing is logged in to.

| Key | |
| --- | --- |
| Up / Down | List: move between posts. Post: scroll |
| OK | List: open the post (on the gold card, the post it came from). Post: the next picture of a carousel |
| Left / Right | Post: the newer / older post |
| Menu (left soft key) | Refresh, Open in browser |
| Back | Back to the list, then out |
