# New Yorker, for the Sonim XP3

A reader for The New Yorker's articles on the XP3's 240x320 screen, laid out after the New Yorker app: Today (the front page), the Magazine (the current issue) and Saved, white pages with the site's red rubrics and the text set in Caslon, each section of a piece opening on a drop cap.

It reads the site's own pages, which carry each article whole in their HTML, so it needs no account, no API and no script. Only articles: podcasts, puzzles, video and cartoon galleries are left out of the lists.

## Keys

In the lists:

| Key | |
| --- | --- |
| Up / Down | Choose a story |
| OK | Read it |
| Left / Right | Today, Magazine, Saved |
| Menu | Open, Refresh; Remove from Saved on a saved story |

Reading:

| Key | |
| --- | --- |
| Down, Right | Next screen |
| Up, Left | Previous screen |
| \* / # | Smaller / larger text |
| Menu | Save (or remove), text size, update the saved copy, back to top |
| Back | Back to the list |

## Offline

The last copy of Today and of the Magazine opens at once on launch, while a fresh one is fetched. A saved article is kept whole on the phone and opens without the network; its pictures still need it.
